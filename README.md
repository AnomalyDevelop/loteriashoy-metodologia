# Loterías Hoy: metodología pública

Este repositorio documenta cómo [Loterías Hoy](https://loteriashoy.net/) organiza resultados históricos sin presentarlos como predicciones.

La web identifica la fuente, la fecha y el estado de cada sorteo. Su [tabla pública de metodología y cobertura](https://loteriashoy.net/metodologia-y-cobertura/) muestra el primer y el último registro disponibles por juego, porque la cobertura real cambia según lo que cada fuente permite recuperar y verificar.

## Qué publica

- Resultados recientes con hora y estado.
- Históricos consultables por lotería y juego.
- Frecuencias y repeticiones del período observado.
- Un [registro público de correcciones](https://loteriashoy.net/correcciones/).

## Qué no afirma

Una frecuencia histórica describe los datos guardados. No garantiza el próximo resultado ni cambia las probabilidades de un sorteo independiente. Loterías Hoy tampoco vende boletos, recibe apuestas, gestiona premios ni representa a los operadores cuyos resultados consulta.

## Verificación

La referencia final de un premio es siempre el operador oficial. Si encuentras una diferencia, comprueba primero esa fuente y luego reporta el juego, la fecha y el número en duda mediante los canales publicados en Loterías Hoy.

## Recurso citable y consultas por número

La página de [metodología y cobertura](https://loteriashoy.net/metodologia-y-cobertura/) calcula desde la base publicada cuántos juegos y sorteos están disponibles, el rango de fechas real y la cobertura individual de cada juego. También expone esos datos como `Dataset` y ofrece una referencia sugerida para que un medio o proyecto de investigación pueda citar la fuente correcta sin confundirla con un operador oficial.

Las fichas de números responden una pregunta distinta: cuándo apareció un número dentro de la ventana observada y cuántas veces figura por juego. Por ejemplo, la [ficha del número 50](https://loteriashoy.net/numero/50/) muestra primero la aparición más reciente disponible y después el desglose de 30, 60 y 90 días. Esa respuesta sigue siendo descriptiva y no se presenta como recomendación de juego.

Medios, proveedores de datos u operadores que quieran revisar una fuente, proponer una corrección o evaluar una colaboración pueden consultar las [reglas de alianzas y publicidad](https://loteriashoy.net/alianzas-y-publicidad/). Una relación comercial no puede cambiar resultados, fuentes, cobertura ni conclusiones estadísticas.
