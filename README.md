# Loterías Hoy: metodología pública

Este repositorio documenta cómo [Loterías Hoy](https://loteriashoy.net/) organiza resultados históricos sin presentarlos como predicciones.

La web identifica la fuente, la fecha y el estado de cada sorteo. Su [tabla pública de metodología y cobertura](https://loteriashoy.net/metodologia-y-cobertura/) muestra el primer y el último registro disponibles por juego, porque la cobertura real cambia según lo que cada fuente permite recuperar y verificar.

## Qué publica

- Resultados recientes con hora y estado.
- Históricos consultables por lotería y juego.
- Frecuencias y repeticiones del período observado.
- Un [registro público de correcciones](https://loteriashoy.net/correcciones/).

## Qué no afirma

Una frecuencia histórica describe los datos guardados. No garantiza el próximo resultado ni cambia las probabilidades de un sorteo independiente. Loterías Hoy tampoco vende boletos, recibe apuestas, gestiona premios ni representa a los operadores cuyos resultados consulta.

## Verificación

La referencia final de un premio es siempre el operador oficial. Si encuentras una diferencia, comprueba primero esa fuente y luego reporta el juego, la fecha y el número en duda mediante los canales publicados en Loterías Hoy.
