# Procedencia y fuentes de resultados

Un histórico solo es útil cuando cada resultado puede relacionarse con una lotería, un juego, una fecha y una fuente. La página de [metodología y cobertura](https://loteriashoy.net/metodologia-y-cobertura/) muestra la procedencia disponible y el rango real de cada juego.

## Qué conviene comprobar

1. Que el nombre del juego corresponda al sorteo consultado.
2. Que la fecha sea la del sorteo y no únicamente la fecha de publicación.
3. Que el formato de los números no haya perdido ceros iniciales.
4. Que cualquier diferencia se contraste con el operador oficial.

## Cuando las fuentes difieren

Una fuente puede corregir un dato, publicar tarde o cambiar su presentación. Loterías Hoy mantiene un [registro público de correcciones](https://loteriashoy.net/correcciones/) para que una rectificación no quede escondida. La fuente oficial correspondiente sigue siendo la referencia definitiva para validar premios.
