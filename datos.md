# Datos de cobertura y licencia

Los archivos [CSV](https://loteriashoy.net/metodologia-y-cobertura/?descargar_cobertura=csv) y [JSON](https://loteriashoy.net/metodologia-y-cobertura/?descargar_cobertura=json) describen el alcance del histórico publicado. No son una exportación de números ganadores.

## Campos principales

| Campo | Significado |
|---|---|
| `lottery_key` | Identificador estable de la lotería. |
| `game_key` | Identificador estable del juego. |
| `first_date` y `last_date` | Primer y último sorteo disponibles en la base publicada. |
| `stored_draws` | Cantidad de sorteos almacenados para ese juego. |
| `expected_draws` | Estimación del total esperado según calendario y ventana objetivo. |
| `coverage_percent` | Proporción entre sorteos almacenados y esperados. |
| `coverage_status` | Estado resumido de disponibilidad. |
| `source_keys` | Identificadores de las fuentes que aportaron registros. |
